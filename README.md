## Key Project — CART-TRACE

Repository: `pskeffington/CART-TRACE`

CART-TRACE is a synthetic-first research framework for reconstructing post-infusion hospital care trajectories following CAR T-cell therapy. Its current public scholarly package includes deterministic episode/state reconstruction, utilization measures, synthetic truth-set validation, reproducibility controls, and governed-data readiness methods. A separate synthetic administrative access-gating extension remains outside the frozen capstone scope and does not determine clinical eligibility, coverage, treatment readiness, or authorization.

## Supporting Evidence Lanes

Current supporting research includes biomedical signal evaluation, imaging robustness, health-services research, humanitarian WASH, municipal GIS/provenance, preparedness systems, ML-assisted document review, and computational-topology/provenance studies. Public claims should be promoted only after the underlying repository has a bounded evidence object with provenance, validation status, uncertainty/missingness, and a clear claim boundary.

## Evidence Promotion Rule

```text
source
  -> repository-specific transformation
  -> repository-specific validation
  -> bounded evidence object
  -> portfolio evidence envelope
  -> public claim
```

A public portfolio or CV claim should not precede the evidence object that supports it.

## Repository Governance

Current-facing README material describes present project state. Historical baselines, superseded architecture, older weekly activity, and prior milestones belong in dated documentation rather than headline pages. Stable repositories do not need cosmetic commits solely to appear recent.

## Public Research Boundary

This public repository does not reproduce private implementation details, credentials, governed source text, private storage locations, PHI, restricted records, or sensitive operational information. Public documentation may describe research goals, architecture, validation state, reproducibility methods, limitations, publication direction, and sanitized aggregate evidence.
